Génère le fichier Markdown du plan d’entraînement hebdomadaire.

  • plan (TrainingPlan) – Plan d’entraînement généré par Claude.

  • player_name (str) – Nom du joueur.

  • player_elo (int) – Elo courant.

  • output_dir (Path) – Dossier de sortie.

  • gm_studies (list[OpeningStudy] | None) – Études de parties de GM.

Return type:

Path

Returns:

Chemin du fichier Markdown généré.
