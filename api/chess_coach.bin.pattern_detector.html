chess_coach.bin.pattern_detector.build_weakness_profile(reports)[source]

Agrège les rapports de parties en un profil de faiblesses.

Les ouvertures problématiques sont agrégées par code ECO (toujours présent dans les annotations caissAI) et non par nom d’ouverture (absent dans les anciennes annotations).

Parameters:

reports (list[GameReport]) – Rapports issus de analyzer.report_from_pgn.

Return type:

WeaknessProfile

Returns:

Profil structuré prêt à être consommé par coach.generate_weekly_plan.

Examples

>>> from chess_coach.bin.analyzer import GameReport
>>> profile = build_weakness_profile([])
>>> profile["total_games"]
0
>>> profile["weakest_phase"]
'middlegame'
