chess_coach.bin.coach.generate_weekly_plan(profile, player_elo, max_daily_minutes=45, model='claude-sonnet-4-5', gm_studies=None)[source]

Génère un plan d’entraînement hebdomadaire personnalisé via Claude.

Le prompt envoie à Claude : - Les statistiques agrégées (ACPL, phase faible, ventilation erreurs) - Les 10 pires positions avec leur commentaire caissAI - Les études de parties de GM pour les ouvertures problématiques

Parameters:

  • profile (WeaknessProfile) – Profil de faiblesses construit par pattern_detector.

  • player_elo (int) – Elo courant du joueur (pour calibrer la difficulté).

  • max_daily_minutes (int) – Durée maximale d’entraînement par jour.

  • model (str) – Modèle Claude à utiliser. Défaut : ANTHROPIC_MODEL dans .env, sinon “claude-sonnet-4-5”.

  • gm_studies (list[OpeningStudy] | None) – Études de parties de GM récupérées depuis la Masters API Lichess. Si fourni, enrich le prompt avec les exemples de GM.

Return type:

TrainingPlan

Returns:

Plan d’entraînement structuré sur 7 jours.

Raises:

  • anthropic.APIError – En cas d’erreur API Claude.

  • json.JSONDecodeError – Si Claude retourne du JSON invalide.
