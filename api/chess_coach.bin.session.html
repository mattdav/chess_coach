chess_coach.bin.session module

Orchestrateur de session de coaching.

chess_coach.bin.session.run_session(pgn_games, player_elo, player_name='', lichess_token='', caissai_config_path=None, max_daily_minutes=45, db_path='chess_coach.db', output_dir=None, podcast_dir=None, max_podcasts=3, dry_run=False, generate_podcast=False, model='claude-sonnet-4-5')[source]

Exécute une session de coaching depuis des parties déjà annotées par caissAI.

Pipeline en 4 étapes : 1. Extraction des erreurs depuis les PGN annotés (NAGs caissAI) 2. Profil de faiblesses agrégé 3. Parties GM Lichess Masters + plan Claude + livrable Markdown 4. Podcasts podgenai (optionnel) + persistance SQLite

Parameters:

  • pgn_games (list[Game]) – Parties PGN déjà annotées par caissAI.

  • player_elo (int) – Elo courant.

  • player_name (str) – Nom du joueur pour filtrer ses erreurs (correspondance partielle). Si vide, toutes les erreurs sont remontées.

  • max_daily_minutes (int) – Durée max entraînement par jour (pour Claude).

  • db_path (str | Path) – Chemin vers la base SQLite. Normalement fourni par la CLI, qui le résout depuis CHESS_COACH_DATA_DIR.

  • lichess_token (str) – Token Lichess OAuth pour récupérer les parties GM (générer sur https://lichess.org/account/oauth/token). Si vide, l’étape parties GM est ignorée.

  • output_dir (Path | None) – Dossier de sortie pour le plan Markdown. Normalement fourni par la CLI, qui le résout depuis CHESS_COACH_PLANS_DIR. Si None, écrit dans plans/ relatif au dossier courant.

  • podcast_dir (Path | None) – Dossier de sortie des MP3 podgenai. Si None, se place sous output_dir/podcasts/.

  • max_podcasts (int) – Nombre maximum de podcasts à générer.

  • dry_run (bool) – Extrait les erreurs sans appel Claude ni écriture SQLite.

  • generate_podcast (bool) – Active la génération de podcasts podgenai.

  • model (str) – Modèle Claude. Défaut : ANTHROPIC_MODEL dans .env, sinon “claude-sonnet-4-5”.

Return type:

tuple[WeaknessProfile, TrainingPlan | None]

Returns:

Tuple (WeaknessProfile, TrainingPlan | None).
